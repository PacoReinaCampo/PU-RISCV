## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**  | **Variable-Fields** | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                          |
|:--------------|:----------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_t`        | `tbegin`  | `rd`                | `Begin a transaction by checkpointing integer registers, saving the abort continuation and status destination, and enabling memory access tracking. Write zero to rd on successful entry or a nonzero status on entry failure. A subsequent abort restores the checkpoint, writes the abort status to the original rd, and resumes immediately after this instruction. Requires rd != X0. A nested begin aborts the active transaction.` |
| `rv_t`        | `tcommit` | `none`              | `Validate the active transaction and atomically publish its speculative memory writes. Preserve the computed integer register values and leave transactional execution on success. Abort if validation or commit fails. Raise CAUSE_ILLEGAL_INSTRUCTION if no transaction is active.`                                                                                                                                                    |
| `rv_t`        | `tabort`  | `uimm12`            | `Explicitly abort the active transaction, discard its speculative memory writes, restore its integer register checkpoint, and resume at its saved abort continuation. Encode uimm12 in the abort status returned through the original tbegin destination register. Raise CAUSE_ILLEGAL_INSTRUCTION if no transaction is active.`                                                                                                         |
| `rv_t`        | `ttest`   | `rd`                | `Write one to rd if a transaction is active, or zero otherwise. Preserve transactional state. This instruction provides neither memory ordering nor a guarantee of successful commit. Writes to X0 are discarded.`                                                                                                                                                                                                                       |

:RVT - Specific Extension for Transactional Memory Instructions
