## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**     | **Variable-Fields**          | **Description**                                                                                                                                                                                                                             |
|:--------------|:-------------|:-----------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_f`        | `fadd_s`     | `rd, rs1, rs2, rm`           | `Add the values in rs1 and rs2 and write the single-precision result to rd using rounding mode rm`                                                                                                                                          |
| `rv_f`        | `fclass_s`   | `rd, rs1`                    | `Write a 10-bit classification mask for the single-precision value in rs1 to integer register rd`                                                                                                                                           |
| `rv_f`        | `fcvt_s_w`   | `rd, rs1, rm`                | `Convert the 32-bit signed integer in rs1 to a single-precision value and write the result to floating-point register rd using rounding mode rm`                                                                                            |
| `rv_f`        | `fcvt_s_wu`  | `rd, rs1, rm`                | `Convert the 32-bit unsigned integer in rs1 to a single-precision value and write the result to floating-point register rd using rounding mode rm`                                                                                          |
| `rv_f`        | `fcvt_w_s`   | `rd, rs1, rm`                | `Convert the single-precision value in rs1 to a 32-bit signed integer and write the result to integer register rd using rounding mode rm. Sign-extend the 32-bit result to XLEN`                                                            |
| `rv_f`        | `fcvt_wu_s`  | `rd, rs1, rm`                | `Convert the single-precision value in rs1 to a 32-bit unsigned integer and write the result to integer register rd using rounding mode rm. Sign-extend the 32-bit result to XLEN`                                                          |
| `rv_f`        | `fdiv_s`     | `rd, rs1, rs2, rm`           | `Divide the value in rs1 by the value in rs2 and write the single-precision result to rd using rounding mode rm`                                                                                                                            |
| `rv_f`        | `feq_s`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the single-precision value in rs1 is equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                              |
| `rv_f`        | `fle_s`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the single-precision value in rs1 is less than or equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag for either kind of NaN`                                   |
| `rv_f`        | `flt_s`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the single-precision value in rs1 is less than the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag for either kind of NaN`                                               |
| `rv_f`        | `flw`        | `rd, rs1, imm12`             | `Load 32 bits from the address in integer register rs1 plus signed offset imm12 into floating-point register rd`                                                                                                                            |
| `rv_f`        | `fmadd_s`    | `rd, rs1, rs2, rs3, rm`      | `Multiply rs1 by rs2 and add rs3 and write the single-precision result to rd using rounding mode rm. Round only once`                                                                                                                       |
| `rv_f`        | `fmax_s`     | `rd, rs1, rs2`               | `Write the single-precision maximum of rs1 and rs2 to rd. Return the numeric input when only one input is NaN and the canonical NaN when both are NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs` |
| `rv_f`        | `fmin_s`     | `rd, rs1, rs2`               | `Write the single-precision minimum of rs1 and rs2 to rd. Return the numeric input when only one input is NaN and the canonical NaN when both are NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs` |
| `rv_f`        | `fmsub_s`    | `rd, rs1, rs2, rs3, rm`      | `Multiply rs1 by rs2 and subtract rs3 and write the single-precision result to rd using rounding mode rm. Round only once`                                                                                                                  |
| `rv_f`        | `fmul_s`     | `rd, rs1, rs2, rm`           | `Multiply the values in rs1 and rs2 and write the single-precision result to rd using rounding mode rm`                                                                                                                                     |
| `rv_f`        | `fmv_w_x`    | `rd, rs1`                    | `Copy the low 32 bits of integer register rs1 into floating-point register rd`                                                                                                                                                              |
| `rv_f`        | `fmv_x_w`    | `rd, rs1`                    | `Copy the low 32 bits of floating-point register rs1 into integer register rd with sign extension to XLEN`                                                                                                                                  |
| `rv_f`        | `fnmadd_s`   | `rd, rs1, rs2, rs3, rm`      | `Negate the product of rs1 and rs2 and subtract rs3 and write the single-precision result to rd using rounding mode rm. Round only once`                                                                                                    |
| `rv_f`        | `fnmsub_s`   | `rd, rs1, rs2, rs3, rm`      | `Negate the product of rs1 and rs2 and add rs3 and write the single-precision result to rd using rounding mode rm. Round only once`                                                                                                         |
| `rv_f`        | `fsgnjn_s`   | `rd, rs1, rs2`               | `Copy the magnitude of the single-precision value in rs1 into rd and set its sign to the inverted sign of rs2`                                                                                                                              |
| `rv_f`        | `fsgnj_s`    | `rd, rs1, rs2`               | `Copy the magnitude of the single-precision value in rs1 into rd and set its sign to the sign of rs2`                                                                                                                                       |
| `rv_f`        | `fsgnjx_s`   | `rd, rs1, rs2`               | `Copy the magnitude of the single-precision value in rs1 into rd and set its sign to the XOR of the signs of rs1 and rs2`                                                                                                                   |
| `rv_f`        | `fsqrt_s`    | `rd, rs1, rm`                | `Compute the square root of rs1 and write the single-precision result to rd using rounding mode rm`                                                                                                                                         |
| `rv_f`        | `fsub_s`     | `rd, rs1, rs2, rm`           | `Subtract rs2 from rs1 and write the single-precision result to rd using rounding mode rm`                                                                                                                                                  |
| `rv_f`        | `fsw`        | `imm12hi, rs1, rs2, imm12lo` | `Store the low 32 bits of floating-point register rs2 to the address in integer register rs1 plus the signed offset formed from imm12hi and imm12lo`                                                                                        |
| `rv_f_zfa`    | `fleq_s`     | `rd, rs1, rs2`               | `Set integer register rd to 1 when the single-precision value in rs1 is less than or equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                 |
| `rv_f_zfa`    | `fli_s`      | `rd, rs1`                    | `Use the encoded rs1 field as an index into the single-precision immediate table and load that constant into rd`                                                                                                                            |
| `rv_f_zfa`    | `fltq_s`     | `rd, rs1, rs2`               | `Set integer register rd to 1 when the single-precision value in rs1 is less than the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                             |
| `rv_f_zfa`    | `fmaxm_s`    | `rd, rs1, rs2`               | `Write the single-precision maximum of rs1 and rs2 to rd. Return the canonical NaN if either input is NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs`                                             |
| `rv_f_zfa`    | `fminm_s`    | `rd, rs1, rs2`               | `Write the single-precision minimum of rs1 and rs2 to rd. Return the canonical NaN if either input is NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs`                                             |
| `rv_f_zfa`    | `froundnx_s` | `rd, rs1, rm`                | `Round the single-precision value in rs1 to an integral floating-point value using rm and write it to rd. Set the invalid flag for signaling NaNs and the inexact flag when a non-NaN input changes`                                        |
| `rv_f_zfa`    | `fround_s`   | `rd, rs1, rm`                | `Round the single-precision value in rs1 to an integral floating-point value using rm and write it to rd. Set the invalid flag for signaling NaNs. Suppress the inexact flag`                                                               |
