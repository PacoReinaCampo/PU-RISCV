## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**     | **Variable-Fields**          | **Description**                                                                                                                                                                                                                                |
|:--------------|:-------------|:-----------------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_q`        | `fadd_q`     | `rd, rs1, rs2, rm`           | `Add the values in rs1 and rs2 and write the quadruple-precision result to rd using rounding mode rm`                                                                                                                                          |
| `rv_q`        | `fclass_q`   | `rd, rs1`                    | `Write a 10-bit classification mask for the quadruple-precision value in rs1 to integer register rd`                                                                                                                                           |
| `rv_q`        | `fcvt_d_q`   | `rd, rs1, rm`                | `Convert the quadruple-precision value in rs1 to a double-precision value and write the result to floating-point register rd using rounding mode rm`                                                                                           |
| `rv_q`        | `fcvt_q_d`   | `rd, rs1, rm`                | `Convert the double-precision value in rs1 to a quadruple-precision value and write the result to floating-point register rd. The conversion is exact and rm does not affect the result`                                                       |
| `rv_q`        | `fcvt_q_s`   | `rd, rs1, rm`                | `Convert the single-precision value in rs1 to a quadruple-precision value and write the result to floating-point register rd. The conversion is exact and rm does not affect the result`                                                       |
| `rv_q`        | `fcvt_q_w`   | `rd, rs1, rm`                | `Convert the 32-bit signed integer in rs1 to a quadruple-precision value and write the result to floating-point register rd. The conversion is exact and rm does not affect the result`                                                        |
| `rv_q`        | `fcvt_q_wu`  | `rd, rs1, rm`                | `Convert the 32-bit unsigned integer in rs1 to a quadruple-precision value and write the result to floating-point register rd. The conversion is exact and rm does not affect the result`                                                      |
| `rv_q`        | `fcvt_s_q`   | `rd, rs1, rm`                | `Convert the quadruple-precision value in rs1 to a single-precision value and write the result to floating-point register rd using rounding mode rm`                                                                                           |
| `rv_q`        | `fcvt_w_q`   | `rd, rs1, rm`                | `Convert the quadruple-precision value in rs1 to a 32-bit signed integer and write the result to integer register rd using rounding mode rm. Sign-extend the 32-bit result to XLEN`                                                            |
| `rv_q`        | `fcvt_wu_q`  | `rd, rs1, rm`                | `Convert the quadruple-precision value in rs1 to a 32-bit unsigned integer and write the result to integer register rd using rounding mode rm. Sign-extend the 32-bit result to XLEN`                                                          |
| `rv_q`        | `fdiv_q`     | `rd, rs1, rs2, rm`           | `Divide the value in rs1 by the value in rs2 and write the quadruple-precision result to rd using rounding mode rm`                                                                                                                            |
| `rv_q`        | `feq_q`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the quadruple-precision value in rs1 is equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                              |
| `rv_q`        | `fle_q`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the quadruple-precision value in rs1 is less than or equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag for either kind of NaN`                                   |
| `rv_q`        | `flq`        | `rd, rs1, imm12`             | `Load 128 bits from the address in integer register rs1 plus signed offset imm12 into floating-point register rd`                                                                                                                              |
| `rv_q`        | `flt_q`      | `rd, rs1, rs2`               | `Set integer register rd to 1 when the quadruple-precision value in rs1 is less than the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag for either kind of NaN`                                               |
| `rv_q`        | `fmadd_q`    | `rd, rs1, rs2, rs3, rm`      | `Multiply rs1 by rs2 and add rs3 and write the quadruple-precision result to rd using rounding mode rm. Round only once`                                                                                                                       |
| `rv_q`        | `fmax_q`     | `rd, rs1, rs2`               | `Write the quadruple-precision maximum of rs1 and rs2 to rd. Return the numeric input when only one input is NaN and the canonical NaN when both are NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs` |
| `rv_q`        | `fmin_q`     | `rd, rs1, rs2`               | `Write the quadruple-precision minimum of rs1 and rs2 to rd. Return the numeric input when only one input is NaN and the canonical NaN when both are NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs` |
| `rv_q`        | `fmsub_q`    | `rd, rs1, rs2, rs3, rm`      | `Multiply rs1 by rs2 and subtract rs3 and write the quadruple-precision result to rd using rounding mode rm. Round only once`                                                                                                                  |
| `rv_q`        | `fmul_q`     | `rd, rs1, rs2, rm`           | `Multiply the values in rs1 and rs2 and write the quadruple-precision result to rd using rounding mode rm`                                                                                                                                     |
| `rv_q`        | `fnmadd_q`   | `rd, rs1, rs2, rs3, rm`      | `Negate the product of rs1 and rs2 and subtract rs3 and write the quadruple-precision result to rd using rounding mode rm. Round only once`                                                                                                    |
| `rv_q`        | `fnmsub_q`   | `rd, rs1, rs2, rs3, rm`      | `Negate the product of rs1 and rs2 and add rs3 and write the quadruple-precision result to rd using rounding mode rm. Round only once`                                                                                                         |
| `rv_q`        | `fsgnjn_q`   | `rd, rs1, rs2`               | `Copy the magnitude of the quadruple-precision value in rs1 into rd and set its sign to the inverted sign of rs2`                                                                                                                              |
| `rv_q`        | `fsgnj_q`    | `rd, rs1, rs2`               | `Copy the magnitude of the quadruple-precision value in rs1 into rd and set its sign to the sign of rs2`                                                                                                                                       |
| `rv_q`        | `fsgnjx_q`   | `rd, rs1, rs2`               | `Copy the magnitude of the quadruple-precision value in rs1 into rd and set its sign to the XOR of the signs of rs1 and rs2`                                                                                                                   |
| `rv_q`        | `fsq`        | `imm12hi, rs1, rs2, imm12lo` | `Store the low 128 bits of floating-point register rs2 to the address in integer register rs1 plus the signed offset formed from imm12hi and imm12lo`                                                                                          |
| `rv_q`        | `fsqrt_q`    | `rd, rs1, rm`                | `Compute the square root of rs1 and write the quadruple-precision result to rd using rounding mode rm`                                                                                                                                         |
| `rv_q`        | `fsub_q`     | `rd, rs1, rs2, rm`           | `Subtract rs2 from rs1 and write the quadruple-precision result to rd using rounding mode rm`                                                                                                                                                  |
| `rv_q_zfa`    | `fleq_q`     | `rd, rs1, rs2`               | `Set integer register rd to 1 when the quadruple-precision value in rs1 is less than or equal to the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                 |
| `rv_q_zfa`    | `fli_q`      | `rd, rs1`                    | `Use the encoded rs1 field as an index into the quadruple-precision immediate table and load that constant into rd`                                                                                                                            |
| `rv_q_zfa`    | `fltq_q`     | `rd, rs1, rs2`               | `Set integer register rd to 1 when the quadruple-precision value in rs1 is less than the value in rs2, or to 0 otherwise. A NaN input yields 0 and sets the invalid flag only for a signaling NaN`                                             |
| `rv_q_zfa`    | `fmaxm_q`    | `rd, rs1, rs2`               | `Write the quadruple-precision maximum of rs1 and rs2 to rd. Return the canonical NaN if either input is NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs`                                             |
| `rv_q_zfa`    | `fminm_q`    | `rd, rs1, rs2`               | `Write the quadruple-precision minimum of rs1 and rs2 to rd. Return the canonical NaN if either input is NaN. Order negative zero below positive zero and set the invalid flag for signaling NaNs`                                             |
| `rv_q_zfa`    | `froundnx_q` | `rd, rs1, rm`                | `Round the quadruple-precision value in rs1 to an integral floating-point value using rm and write it to rd. Set the invalid flag for signaling NaNs and the inexact flag when a non-NaN input changes`                                        |
| `rv_q_zfa`    | `fround_q`   | `rd, rs1, rm`                | `Round the quadruple-precision value in rs1 to an integral floating-point value using rm and write it to rd. Set the invalid flag for signaling NaNs. Suppress the inexact flag`                                                               |
| `rv_q_zfhmin` | `fcvt_h_q`   | `rd, rs1, rm`                | `Convert the quadruple-precision value in rs1 to a half-precision value and write the result to floating-point register rd using rounding mode rm`                                                                                             |
| `rv_q_zfhmin` | `fcvt_q_h`   | `rd, rs1, rm`                | `Convert the half-precision value in rs1 to a quadruple-precision value and write the result to floating-point register rd. The conversion is exact and rm does not affect the result`                                                         |
