## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**          | **Variable-Fields** | **Description**                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
|:--------------|:------------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_u`        | `utrapret`        | `none`              | `Experimental SYSTEM return through an active supervisor-authorized native user frame owned by the current context. Check extension support, context ownership, and frame validity before effects. Restore its saved user notification enable, invalidate the frame, and resume U-mode at its saved PC without changing address space. Software restores general-purpose registers. The protected frame is separate from the draft N uepc state. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                      |
| `rv_usctr`    | `uctrclr`         | `none`              | `Experimental SYSTEM operation on the control transfer record bank delegated to the current native user context. Check extension support, context ownership, and supervisor permission before effects. Clear only that bank's entries, cycle counter, and counter-valid state; preserve recording control and all other banks. Denied access raises an illegal-instruction exception. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                 |
| `rv_u`        | `ufence_vma`      | `rs1, rs2`          | `Experimental SYSTEM fence within a supervisor-authorized native user translation scope. Validate extension support, ownership, and selectors before effects; denied access raises an illegal-instruction exception. Order earlier visible stores before later local translation-table reads and invalidate matching translations only in that scope. X0 selects all authorized values; nonzero rs1 selects X[rs1] as a virtual address and nonzero rs2 selects the low ASIDLEN bits of X[rs2]. Never modify page tables or synchronize remote harts. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.` |
| `rv_uvinval`  | `uinval_vma`      | `rs1, rs2`          | `Experimental SYSTEM invalidation within a supervisor-authorized native user translation scope. Validate extension support, ownership, and selectors before effects; denied access raises an illegal-instruction exception. Invalidate matching local translations without implicit ordering. X0 selects all authorized values; nonzero rs1 selects X[rs1] as a virtual address and nonzero rs2 selects the low ASIDLEN bits of X[rs2]. Never modify page tables, access another context, or synchronize remote harts. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                |
| `rv_uvinval`  | `ufence_inval_ir` | `none`              | `Experimental SYSTEM barrier within the current supervisor-authorized native user translation scope. Check extension support, ownership, and permission before effects; denied access raises an illegal-instruction exception. Order earlier local uinval_vma invalidations before later implicit translation-table reads for that scope. Do not initiate invalidation or affect other contexts or harts. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                             |
| `rv_uvinval`  | `ufence_w_inval`  | `none`              | `Experimental SYSTEM barrier within the current supervisor-authorized native user translation scope. Check extension support, ownership, and permission before effects; denied access raises an illegal-instruction exception. Order earlier stores visible to this hart before later local uinval_vma invalidations in that scope. Do not initiate invalidation or affect other contexts or harts. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                   |

:RVU - Specific Extension for User-level Instructions
