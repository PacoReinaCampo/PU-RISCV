| `rv_m`         | `mtrapret`        | `none`              | `Experimental SYSTEM machine-only trap return using mepc and mstatus. Restore the saved privilege, virtualization, and interrupt-enable state, clear MPRV when returning below M-mode, and apply implemented return-state extensions. Requires rv_m. Check access before effects; this encoding is independent of standard MRET. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                                                                                                                                                    |
| `rv_msctr`     | `mctrclr`         | `none`              | `Experimental SYSTEM machine-only operation on the machine control transfer record bank. Clear its entries, cycle counter, and counter-valid state while preserving recording control and all supervisor and user banks. Requires rv_msctr; validate access before effects. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                                                                                                                                                                                                         |
| `rv_m`         | `mfence_vma`      | `rs1, rs2`          | `Experimental SYSTEM machine-only operation on S-stage translations. Order earlier visible stores before later local translation-table reads and invalidate matching local translations. Use rs1 to select the virtual address and rs2 to select the ASID. The X0 register selects all values for its operand; a nonzero register containing zero selects address or ID zero. Preserve global mappings when selecting a specific ASID, where applicable. Requires rv_m; validate access before effects. No remote-hart synchronization or page-table modification is implied. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                       |

Preserve global mappings when selecting a specific ASID, where applicable. Requires rv_mvinval; validate access before effects. No remote-hart synchronization or page-table modification is implied. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                   |

Check access before effects. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                                                                                                                                                       |
| `rv_m`         | `mwait`           | `none`              | `Experimental SYSTEM machine-only wait for a locally enabled pending interrupt or another platform-permitted machine event. Global interrupt enables do not prevent wakeup. May execute as a NOP. Resume normally at PC + 4 without acknowledging the event; software must recheck pending state. Requires rv_m. Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                                                                                                                                                                    |

Bits [11:7] are a fixed operation selector and do not designate a GPR destination.`                                                                                                                                                                                                                                                                                                            |
