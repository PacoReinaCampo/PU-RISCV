## INSTRUCTION DESCRIPTIONS

| **Extension**  | **Name**          | **Variable-Fields** | **Description**                                                                                                                                                                                                                           |
|:---------------|:------------------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_sdext`     | `dret`            | `none`              | `Resume normal execution at dpc using the privilege and virtualization state saved in dcsr`                                                                                                                                               |
| `rv_smrnmi`    | `mnret`           | `none`              | `Return to mnepc and restore the saved privilege and virtualization state from mnstatus. Re-enable resumable non-maskable interrupts`                                                                                                     |
| `rv_ssctr`     | `sctrclr`         | `none`              | `Clear all control transfer record entries, the cycle counter, and its validity state, subject to CTR access permissions`                                                                                                                 |
| `rv_s`         | `sfence_vma`      | `rs1, rs2`          | `Order prior visible stores before subsequent local translations and invalidate matching current-stage translations. Use rs1 to select the virtual address and rs2 to select the ASID. An X0 operand selects all values for that operand` |
| `rv_s`         | `sret`            | `none`              | `Restore the saved supervisor interrupt and privilege state and resume at sepc, or at vsepc when returning from a virtual-supervisor trap`                                                                                                |
| `rv_svinval_h` | `hinval_gvma`     | `rs1, rs2`          | `Invalidate matching local G-stage translations. Use rs1 to select the guest physical address shifted right by two bits and rs2 to select the VMID. An X0 operand selects all values for that operand`                                    |
| `rv_svinval_h` | `hinval_vvma`     | `rs1, rs2`          | `Invalidate matching local VS-stage translations within the current VMID. Use rs1 to select the guest virtual address and rs2 to select the ASID. An X0 operand selects all values for that operand`                                      |
| `rv_svinval`   | `sfence_inval_ir` | `none`              | `Order prior local Svinval invalidations before subsequent implicit references to address-translation structures`                                                                                                                         |
| `rv_svinval`   | `sfence_w_inval`  | `none`              | `Order prior stores visible to the local hart before subsequent local Svinval invalidations`                                                                                                                                              |
| `rv_svinval`   | `sinval_vma`      | `rs1, rs2`          | `Invalidate matching local current-stage translations. Use rs1 to select the virtual address and rs2 to select the ASID. An X0 operand selects all values for that operand`                                                               |
| `rv_system`    | `mret`            | `none`              | `Restore the saved machine interrupt and privilege state and resume at mepc`                                                                                                                                                              |
| `rv_system`    | `wfi`             | `none`              | `Allow the hart to stall until a locally enabled interrupt becomes pending or another permitted wake event occurs`                                                                                                                        |

:RVS - Specific Extension for Supervisor-level Instructions
