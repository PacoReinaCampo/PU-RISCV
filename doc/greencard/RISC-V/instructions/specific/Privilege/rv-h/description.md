## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**      | **Variable-Fields** | **Description**                                                                                                                                                                                                                                                                                |
|:--------------|:--------------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_h`        | `hfence_gvma` | `rs1, rs2`          | `Order prior stores before subsequent local G-stage translations and invalidate matching translations. Select the guest physical address shifted right by 2 bits with rs1 and the VMID with rs2. An X0 operand selects all values for that operand`                                            |
| `rv_h`        | `hfence_vvma` | `rs1, rs2`          | `Order prior stores before subsequent local VS-stage translations and invalidate matching translations. Select the guest virtual address with rs1 and the ASID with rs2. An X0 operand selects all values for that operand within the current VMID`                                            |
| `rv_h`        | `hlv_b`       | `rd, rs1`           | `Load a 8-bit value from the guest virtual address in rs1 using two-stage translation and sign-extend the result into rd`                                                                                                                                                                      |
| `rv_h`        | `hlv_bu`      | `rd, rs1`           | `Load a 8-bit value from the guest virtual address in rs1 using two-stage translation and zero-extend the result into rd`                                                                                                                                                                      |
| `rv_h`        | `hlv_h`       | `rd, rs1`           | `Load a 16-bit value from the guest virtual address in rs1 using two-stage translation and sign-extend the result into rd`                                                                                                                                                                     |
| `rv_h`        | `hlv_hu`      | `rd, rs1`           | `Load a 16-bit value from the guest virtual address in rs1 using two-stage translation and zero-extend the result into rd`                                                                                                                                                                     |
| `rv_h`        | `hlv_w`       | `rd, rs1`           | `Load a 32-bit value from the guest virtual address in rs1 using two-stage translation and sign-extend the result into rd`                                                                                                                                                                     |
| `rv_h`        | `hlvx_hu`     | `rd, rs1`           | `Load a 16-bit value from the guest virtual address in rs1 using two-stage translation and zero-extend the result into rd. Require execute permission at both translation stages and read and execute permission at the resulting physical address. Report access failures as load exceptions` |
| `rv_h`        | `hlvx_wu`     | `rd, rs1`           | `Load a 32-bit value from the guest virtual address in rs1 using two-stage translation and zero-extend the result into rd. Require execute permission at both translation stages and read and execute permission at the resulting physical address. Report access failures as load exceptions` |
| `rv_h`        | `hsv_b`       | `rs1, rs2`          | `Store the low 8 bits of rs2 to the guest virtual address in rs1 using two-stage translation and the guest privilege selected by hstatus.SPVP`                                                                                                                                                 |
| `rv_h`        | `hsv_h`       | `rs1, rs2`          | `Store the low 16 bits of rs2 to the guest virtual address in rs1 using two-stage translation and the guest privilege selected by hstatus.SPVP`                                                                                                                                                |
| `rv_h`        | `hsv_w`       | `rs1, rs2`          | `Store the low 32 bits of rs2 to the guest virtual address in rs1 using two-stage translation and the guest privilege selected by hstatus.SPVP`                                                                                                                                                |

:RVH - Specific Extension for Hypervisor-level Instructions

| **Extension** | **Name** | **Variable-Fields** | **Description**                                                                                                                                 |
|:--------------|:---------|:--------------------|:------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv64_h`      | `hlv_d`  | `rd, rs1`           | `Load a 64-bit value from the guest virtual address in rs1 using two-stage translation and sign-extend the result into rd`                      |
| `rv64_h`      | `hlv_wu` | `rd, rs1`           | `Load a 32-bit value from the guest virtual address in rs1 using two-stage translation and zero-extend the result into rd`                      |
| `rv64_h`      | `hsv_d`  | `rs1, rs2`          | `Store the low 64 bits of rs2 to the guest virtual address in rs1 using two-stage translation and the guest privilege selected by hstatus.SPVP` |

:RV64H - Specific Extension for Hypervisor-level Instructions (64 bit)
