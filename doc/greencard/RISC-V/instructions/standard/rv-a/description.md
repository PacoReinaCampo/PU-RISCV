## INSTRUCTION DESCRIPTIONS

| **Extension** | **Name**    | **Variable-Fields**    | **Description**                                                                                                                                                                                                          |
|:--------------|:------------|:-----------------------|:-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_a`        | `amoadd_w`  | `rd, rs1, rs2, aq, rl` | `Load word from address in rs1 into rd, add rd and rs2, write the result to the address in rs1. aq requests acquire ordering and rl requests release ordering.`                                                          |

| `rv_a`        | `amomax_w`  | `rd, rs1, rs2, aq, rl` | `Load word from address in rs1 into rd, find maximum of rd and rs2, write the result to the address in rs1 (signed). aq requests acquire ordering and rl requests release ordering.`                                     |
| `rv_a`        | `amominu_w` | `rd, rs1, rs2, aq, rl` | `Load word from address in rs1 into rd, find minimum of rd and rs2, write the result to the address in rs1 (unsigned). aq requests acquire ordering and rl requests release ordering.`                                   |
