## INSTRUCTION PSEUDO-CODE (PL)

| **Extension** | **Name**  | **Variable-Fields** | **Pseudo-Code**                                                                                                                                                                                                                                                                                                                                                                                |
|:--------------|:----------|:--------------------|:-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_t`        | `tbegin`  | `rd`                | `if (rd == 0) { trap(CAUSE_ILLEGAL_INSTRUCTION); } else if (tx.active) { abort_transaction(NESTED); } else { memory_boundary(); clear_reservation(); status = try_begin(); if (status != 0) { write_register(rd, status); pc += 4; } else { tx.checkpoint = copy(registers); tx.abort_pc = pc + 4; tx.status_rd = rd; clear_tracking(); tx.active = true; write_register(rd, 0); pc += 4; } }` |
| `rv_t`        | `tcommit` | `none`              | `if (!tx.active) { trap(CAUSE_ILLEGAL_INSTRUCTION); } else { status = validate_and_commit_atomically(); if (status != 0) { abort_transaction(status); } else { clear_tracking(); tx.active = false; memory_boundary(); pc += 4; } }`                                                                                                                                                           |
| `rv_t`        | `tabort`  | `uimm12`            | `if (!tx.active) { trap(CAUSE_ILLEGAL_INSTRUCTION); } else { abort_transaction((unsigned_xlen(uimm12) << 16) \| EXPLICIT); }`                                                                                                                                                                                                                                                                  |
| `rv_t`        | `ttest`   | `rd`                | `write_register(rd, tx.active ? 1 : 0); pc += 4;`                                                                                                                                                                                                                                                                                                                                              |
