## INSTRUCTION PSEUDO-CODE (HDL)

| **Extension** | **Name**  | **Variable-Fields** | **Pseudo-Code**                                                                                                                                                                                                                                                                                                                                                      |
|:--------------|:----------|:--------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `rv_t`        | `tbegin`  | `rd`                | `if (rd == 0) trap(CAUSE_ILLEGAL_INSTRUCTION); else if (tx_active) tx_abort(NESTED); else begin memory_boundary(); clear_reservation(); if (entry_status != 0) begin write_gpr(rd, entry_status); pc <= pc + 4; end else begin checkpoint <= gpr; abort_pc <= pc + 4; status_rd <= rd; clear_tracking(); tx_active <= 1'b1; write_gpr(rd, 0); pc <= pc + 4; end end` |
| `rv_t`        | `tcommit` | `none`              | `if (!tx_active) trap(CAUSE_ILLEGAL_INSTRUCTION); else begin validate_and_commit_atomic(commit_status); if (commit_status != 0) tx_abort(commit_status); else begin clear_tracking(); tx_active <= 1'b0; memory_boundary(); pc <= pc + 4; end end`                                                                                                                   |
| `rv_t`        | `tabort`  | `uimm12`            | `if (!tx_active) trap(CAUSE_ILLEGAL_INSTRUCTION); else tx_abort((trunc(uimm12, XLEN) << 16) \| EXPLICIT);`                                                                                                                                                                                                                                                           |
| `rv_t`        | `ttest`   | `rd`                | `write_gpr(rd, tx_active ? trunc(1, XLEN) : trunc(0, XLEN)); pc <= pc + 4;`                                                                                                                                                                                                                                                                                          |

:RVT - Specific Extension for Transactional Memory Instructions
